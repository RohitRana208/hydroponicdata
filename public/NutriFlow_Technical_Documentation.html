1. Executive Summary

NutriFlow is an enterprise-grade Internet of Things (IoT) and Edge Computer Vision hydroponics monitoring platform. It provides continuous, real-time surveillance of vital biochemical, physical, and environmental parameters essential for soilless cultivation.

The system leverages a decoupled dual-microcontroller edge architecture comprising an Arduino Uno R3 (dedicated to high-reliability analog/digital sensor polling and physical user interface interaction) and an ESP32-S3-N16R8 CAM (dedicated to high-bandwidth edge computer vision, data synchronization, and secure TLS cloud communications). Data is persisted in a distributed MongoDB Atlas cluster and displayed via a responsive, cloud-native web dashboard hosted on Vercel.

3. Complete Hardware Pinout Matrix

Component Signal Line Board Pin Voltage Rail Description & Technical Notes
pH Sensor Analog Signal (Po) Arduino Uno A0 5.0 V Analog voltage signal (2.50V corresponds to pH 7.00).
Ultrasonic (HC-SR04) TRIG / ECHO Arduino Uno D12 / D13 5.0 V Water level reservoir depth measurement (10 µs pulse).
Water Temp (DS18B20) Data (DQ) Arduino Uno D10 5.0 V 1-Wire protocol with 4.7 kΩ pull-up resistor to 5V rail.
Room Temp/Hum (DHT11) Data Arduino Uno D11 5.0 V Single-bus digital sensor sampling room climate.
16x2 Character LCD SDA / SCL Arduino Uno A4 / A5 5.0 V I2C backpack interface configured at address 0x27.
4x4 Matrix Keypad Rows R1–R4 Arduino Uno D9, D8, D7, D6 5.0 V Scanned input lines with software pull-ups.
4x4 Matrix Keypad Cols C1–C4 Arduino Uno D5, D4, D3, D2 5.0 V Active-low column drive lines.
Inter-Board UART Link TX / RX Arduino A2 / A1 ↔ ESP32 RX0 / TX0 3.3 V Logic 9600 Baud delimited ASCII stream (GPIO 44 & GPIO 43).
Common Ground Link GND Arduino GND ↔ ESP32 GND 0 V Mandatory: Shared reference ground across boards.
TDS / EC Sensor Analog Signal ESP32-S3 G2 (GPIO 2) 3.3 V Native ADC1_CH1 high-precision 12-bit channel.
TDS Power Rail VCC / GND ESP32-S3 3V3 / GND 3.3 V Only Caution: Do NOT connect to 5V (ESP32 ADC limit is 3.3V).
OV2640 Plant Camera Camera Bus ESP32-S3 Ribbon 3.3 V / 1.8 V Internal parallel bus using board pins G4-G18.
⚠️ Critical Hardware Design Notice:
Pins G4 through G18 on the ESP32-S3-N16R8 CAM board are dedicated exclusively to the internal high-speed parallel bus of the OV2640 camera. Pin G42 is a digital JTAG/MTMS pin with NO analog-to-digital converter (ADC). Pin G2 (GPIO 2, ADC1_CH1) is the official and verified safe analog input for the TDS sensor.

5. Cloud Database Collections & Data Models

All records are stored within the MongoDB Atlas database named hydrocore across 4 distinct collections:

  • sensor_logs: Continuous telemetry logs sampled at 5-second intervals.
  • camera_snapshots: Base64-encoded JPEG image snapshots capturing plant canopy growth.
  • thresholds: Configurable safe operational envelopes with alert thresholds.
  • pending_commands: Asynchronous queue for remote hardware action execution (e.g. on-demand camera capture).

7. Hardware Flashing & Deployment Instructions

7.1 Arduino Uno Master Node

  1. Connect Arduino Uno to your PC via USB cable.
  2. In Arduino IDE, select Tools > Board > Arduino Uno.
  3. Select the corresponding USB Serial Port.
  4. Open firmware/arduino_uno_master.ino and click Upload.

7.2 ESP32-S3-N16R8 CAM Gateway

  1. Connect the USB Type-C cable to the TTL Port (CH340 chip) of the board.
  2. In Arduino IDE, select Tools > Board > esp32 > ESP32S3 Dev Module.
  3. Apply the following exact board configurations:
    • USB CDC On Boot: Enabled
    • CPU Frequency: 240MHz (WiFi)
    • Flash Size: 16MB (128Mb)
    • Partition Scheme: Huge APP (3MB No OTA/1MB SPIFFS)
    • PSRAM: OPI PSRAM
  4. Open firmware/esp32_s3_gateway.ino and click Upload.
